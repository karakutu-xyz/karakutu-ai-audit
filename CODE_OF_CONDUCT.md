# Code of conduct

This project adopts the **Contributor Covenant, version 2.1**, as its code of conduct:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

That document is the reference text. It defines the expected and unacceptable behaviour,
the scope (all project spaces, and public spaces where someone represents the project), and
the enforcement guidelines (correction, warning, temporary ban, permanent ban) that the
maintainers apply.

## Reporting

Report unacceptable behaviour privately to the project maintainers. Until a dedicated
contact address is published here, use GitHub's private reporting on this repository (see
[SECURITY.md](./SECURITY.md)) and mark the report as a conduct matter. All reports are
reviewed promptly and handled confidentially, and the maintainers will respect the privacy
and safety of the reporter.
